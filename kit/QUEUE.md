# Queue

The running to-do list for {{OWNER}} and Kit, highest priority first in each section. Kit keeps it
current, and {{OWNER}} can edit it directly.

Item format: `- [ ] **Title**: due DD-Mmm-YYYY (added DD-Mmm-YYYY, updated DD-Mmm-YYYY)`, with
detail in sub-bullets. Waiting items say who or which agent they're waiting on, and since when.
Finished items move to Done with the date and are cleared after two weeks.

The Sprint section holds the current sprint: `Sprint <name>: DD-Mmm-YYYY to DD-Mmm-YYYY`, then items
like `- [ ] **Title** (S|M|L) [status]`, sized S=1, M=3, L=5 points. Manage it with `todo sprint`.
