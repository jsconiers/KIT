# Demand tracking setup

What the demand tracker uses. It reads this before every job, so keep it current.

- **Systems:** not set. Where demands and tickets live, their number formats, and how to reach each
  one: a connector in Claude Code, notification emails, or documents.
- **Register:** `demands/REGISTER.md` in the library root, unless you set another place here.
- **Scope:** not set. Which demands to track: ones you own, ones you work on, or a list.
