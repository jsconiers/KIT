# Expertise

Topics you're willing to be asked about, for the team's expertise finder (`kit-team experts`). It's
published only when `expertise` is in the Publish list in `sharing.md`, and only by your role and
Kit id, never your name. Levels: aware, working, expert. Evidence: record ids or library file names
that back it up, separated by semicolons. Leave the table empty to share nothing.
