# Inbox triage setup

What `kit-triage` uses to suggest reply, decide, delegate, read-later, or ignore for each message.
Suggestions only: it never moves, flags, or answers mail.

- **My name or address:** optional. How you appear on To and Cc lines, so Cc-only mail can be told
  apart. Until set, the owner name from Kit's config is used.
- **Priority senders:** optional. Comma-separated names or roles whose mail should surface as reply
  or decide, for example your manager and your sponsors.
- **Delegated topics:** optional. Comma-separated words for areas you've handed to others; a request
  that mentions one is suggested as delegate.
