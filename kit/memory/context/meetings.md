# Meeting setup

What the meeting scribe uses. It reads this before every job, so keep it current.

- **Inbox:** not set. The folder where you drop meeting notes and transcripts, and how to name the
  files so the scribe can tell the project manager's notes (`pm`), your own (`architect`), and
  transcripts (`transcript`) apart.
- **Your notes:** not set. The folders where you keep your own notes, which the scribe may read.
- **Project managers:** optional. Who manages each project, so the scribe can find their notes in
  email.
- **Mail:** optional. The command that searches mail (read-only), and the one that creates drafts.
- **Vendor meeting template:** `~/Claude/Agents/kit/templates/vendor-meeting-template.md`, an
  example to adapt. Point here to your team's own if it has one.
- **Awaiting reply after:** 3 days. How long `kit-awaiting` waits before listing sent mail that asked
  for something and got no reply (it needs kitmail's sent-items commands).
