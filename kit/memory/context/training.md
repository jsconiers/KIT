# Training setup

What the training lead uses. It reads this before every job, so keep it current.

- **Folder:** `training/` in the library root (see `library.md`), unless you set another place
  here. Inside it: `plans/`, `materials/`, `skills-matrix.md`, and `LOG.md`.
- **Who plans are for:** not set. For example the owner only, or the owner and the team.
- **Team roles:** not set. The roles in the team, for the skills matrix (roles, not names).
- **Learning platform:** optional. A platform plans should link to. Until set, the lead keeps
  plans in the library and assumes no platform.
- **Template:** `~/Claude/Agents/kit/templates/learning-plan-template.md`, an example to adapt.
- **Weekly time:** optional. Default hours a week for study and labs, when a brief doesn't say.
- **Sharing:** team views show skills by role and counts, never an individual's gaps. Change this
  only to make it stricter.
- **Certifications:** optional. Certifications the team tracks, with renewal rules.
