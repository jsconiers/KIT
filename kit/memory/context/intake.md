# Intake setup

What the intake triager uses. It reads this before every job, so keep it current.

- **Checklist:** not set. The intake checklist or requirements list to work through, where it is,
  and how to read it.
- **When an impact assessment is needed:** not set. Your team's rules, for example by scope, cost,
  risk, or new technology.
- **Projects:** how to name a new project, and where its working folder goes.
- **Questions:** optional. Anything to always ask, and the tone to use with requesters.
