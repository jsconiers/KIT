# Library setup

Where the librarian keeps the library, what it may read, and how it reaches each source. The
librarian reads this before every job, so keep it current.

- **Library root:** not set. Pick a folder for the library. For work documents, use storage your
  employer manages, not Kit's own folder.
- **Published libraries:** none yet. For each one, add its name, where it lives, and how to reach
  it: a connector available in Claude Code, or a folder synced to this computer (on a Mac,
  cloud drives sync under `~/Library/CloudStorage/`).
- **Working folders:** none yet. Add the folders where you keep your own documents and project
  files, mark which one holds your projects, and note any folder that's a copy of another.
