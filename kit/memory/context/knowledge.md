# Knowledge setup

What the curator uses. It reads this before every job, so keep it current.

- **Knowledge base:** `knowledge/` in the library root (see `library.md`), unless you set another
  place here.
- **Sharing:** private: only you see the knowledge base. When you decide to share it, say with whom
  and where.
- **Focus:** optional. The systems, platforms, or topics to cover first, and any kinds of document
  to leave out.
- **System profiles:** `kit-sysprofile <system>` drafts a one-page profile from the library's records,
  every line cited; template `~/Claude/Agents/kit/templates/system-profile-template.md`, an example to
  adapt. Profiles are saved in the project's artifacts folder only with `--write`.
