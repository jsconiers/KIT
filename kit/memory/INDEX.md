# Memory index

One line per memory file: its path and what it holds. This loads every session; open a file
when its line is relevant. Keep this under 100 lines and put detail in the files, not here.

- `glossary.md`: {{OWNER}}'s shorthand, acronyms, nicknames, and project names
- `context/kit-setup.md`: how Kit is installed, and where its files and controls live
- `context/agents.md`: Kit's staff, what each agent does, and how Kit routes work between them
- `context/library.md`: where the librarian keeps the library and how it reaches the published documents
- `context/writing.md`: templates, examples, skills, and output rules for the IA writer, GDS writer, and reviewer
- `context/diagrams.md`: the diagramming standard, stencils, and formats the diagrammer uses
- `context/calendar.md`: the scheduler's calendar tool, working hours, and habits
- `context/letters.md`: the letters desk's return address, letter style, saved signature, and where incoming letters arrive
- `context/demands.md`: where the demand tracker finds demands and tickets, and where it keeps its register
- `context/knowledge.md`: where the curator keeps the knowledge base, what it covers first, and who it's shared with
- `context/connectors.md`: the outside systems the gateway may reach, its direct callers, and the audit log (guard settings in `connector-guard.json`)
- `context/intake.md`: the intake checklist, when an impact assessment is needed, and how projects are named
- `context/meetings.md`: the meeting inbox, where the architect's notes are, and the mail commands the meeting scribe uses
- `context/status.md`: the status report's format, window, and audiences
- `context/sharing.md`: what kit-publish shares with the team, the outbox, the Kit id, and the owner role
- `context/standards.md`: the engineering standards, reference architectures, and baselines the standards checker, red team, and threat modeler use
- `context/compliance.md`: control frameworks, data classes, and sign-off roles for the risk and compliance mapper
- `context/costs.md`: rate cards, labor rates, currency, and contingency for the cost estimator
- `context/changeboard.md`: the change board's template, risk matrix, checklist, and lead times
- `context/decisions.md`: the ADR template, folder, numbering, and sources for the decision recorder
- `context/estimating.md`: past project data, phase model, and roles for the PMO estimator
- `context/onboarding.md`: core reading by role, team conventions, and what's off limits for the onboarding guide
- `context/audit.md`: the auditor's audit folder, reviewers, working hours, and kit-audit thresholds
