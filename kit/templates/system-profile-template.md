# System profile: <system>

An example template for a one-page system profile. `kit-sysprofile <system>` drafts one from the
library's records, citing every line by file and line; the curator or the architect fills in what
the records don't hold. Copy it, change it to suit the team, and point `memory/context/knowledge.md`
at the copy. Delete the guidance lines in angle brackets when filling it in.
